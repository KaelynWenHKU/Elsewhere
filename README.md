# Elsewhere 时差小屋
> Live together, apart.

Elsewhere is an AI-powered cross-timezone emotional companionship platform that rebuilds the feeling of “living together” through shared 3D spaces, AI avatars, spatial replay, and ambient voice memories.

Instead of fragmented messaging, Elsewhere creates a continuous sense of presence between long-distance couples, families, international students, and overseas workers.

---

# Core Idea

Current communication apps only allow people to chat.

But what humans truly need is:

> a shared sense of daily life.

Elsewhere reconstructs daily routines into a synchronized virtual home, allowing users to:

- see where loved ones are
- replay their daily activities
- receive voice memories
- experience ambient companionship across time zones

---

#  Features

## 1. Shared 3D Living Space

* Import LCC/XGRIDS 3D environments
* Rebuild real homes into interactive virtual spaces
* AI avatars move inside the environment in real time

## 2. AI Spatial Replay

* Replay a user’s daily timeline
* Wake up → Kitchen → School → Café → Home
* Create a “24-hour co-living” experience

## 3. AI Companion Avatar

* Digital twin avatars powered by Evaturn API
* Mimic user appearance and movement
* Emotional ambient interaction

## 4. Smart Indoor + Outdoor Tracking

* RSSI WiFi positioning
* GPS / Google Maps integration
* Context-aware activity inference

## 5. Ambient Voice Memory

* Leave asynchronous voice memories
* Voice replay in shared spaces
* Emotional timeline reconstruction

## 6. AI Life Summary

* Daily / weekly / monthly AI-generated summaries
* Emotional memory archive
* AI relationship timeline
